# Копия файлов сайта chastnaja-shkola-lesenka.ru от 14.11.2026

Сохранено 51 файлов, 24 265 936 байт до сжатия. В архиве файлы каталога wp-content/uploads с картинками, видео и связанными ресурсами. Контрольные суммы частей и файлов приложены.

## Проверка и восстановление

1. Склонируйте репозиторий и перейдите в `recovery/snapshot-20261114`.
2. Выполните `sha256sum -c PARTS.sha256`. В пустой временный каталог соберите и распакуйте архив командой `cat files.tar.gz.part-* | tar -xzf - -C /путь/к/временному-каталогу`.
3. Перейдите в распакованный каталог и выполните `sha256sum -c SHA256SUMS`, указав полный путь к манифесту из репозитория.
4. Установите остальные файлы WordPress и восстановите базу. Перенесите файлы из архивного каталога в wp-content/uploads с сохранением путей.

Учётные данные, база, конфигурация и темы берутся из рабочих исходников и резервных копий по [инструкции «Сервер»](https://github.com/suyazov/affine-pages-backup/blob/main/affine/infrastructure/Сервер.md). В архив попали файлы, доступные на сервере на дату снимка.
